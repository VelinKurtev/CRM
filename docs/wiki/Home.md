# CRM

A customer relationship manager: contacts, companies, leads, deals, tasks and reporting, with role-based access.

| Part | What it is |
| --- | --- |
| **crm-app** | The web app: React 19, TypeScript, Vite, Tailwind, shadcn/ui |
| **crm-api** | The REST API: Express 5, Prisma 7, PostgreSQL 16 |
